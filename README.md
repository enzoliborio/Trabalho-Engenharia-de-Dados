# Trabalho de Engenharia de Dados

Este repositório contém as implementações do trabalho prático da disciplina de Engenharia de Dados (2026.1).

## Parte 1: CRUD em Java com PostgreSQL (AWS RDS)

Esta pasta contém o programa em Java que realiza operações de inserção, leitura, atualização e deleção (CRUD) no banco de dados da AWS.

### Como executar:
1. **Pré-requisitos:** Tenha o [JDK](https://adoptium.net/) instalado e o driver JDBC do PostgreSQL no seu classpath.
2. **Configuração:** Abra o arquivo `CrudRelacional.java` e preencha as variáveis de conexão (`USER`, `PASSWORD`) com as credenciais fornecidas pelo professor.
3. **Execução:**
   - Compile: `javac CrudRelacional.java`
   - Rode: `java CrudRelacional`
4. **Uso:** O programa apresentará um menu interativo no terminal. Basta seguir as instruções na tela.
